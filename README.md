# 卡罗西亚大陆（课堂养成游戏）

纯静态网页游戏，原生 HTML / CSS / JavaScript，无框架、无构建、无依赖。给小学到初中信息学课堂用：学生上课做题表现换「洛克贝」，再用洛克贝探索、抓宠物、打战力、买时装。

- 线上：https://zjj223.github.io/
- 仓库：`zjj223/zjj223.github.io`，分支 `main`，GitHub Pages 托管
- 本地：直接双击 `index.html` 即可运行（`file://` 下功能完整）

## 文件结构

```
index.html          页面骨架（三个视图 + 全部弹窗）
app.js              全部逻辑（约 32 万字节，单文件）
styles.css          全部样式（注意：文件带 BOM）
data/petConfig.js   宠物数据库（名称、系别、阶段图、性别池）
assets/pets/        宠物立绘，assets/pets/{male|female}/{petId}/stage-N.png
assets/outfits/     人物时装立绘 480×640 透明 PNG（boy-*/girl-*）
assets/boxworld/    新手装 sprite
assets/vendor/      第三方库（supabase.js，多人可见的实时通道）
tools/              数值自测脚本（Python，不参与线上运行）
```

发布新版时把 `index.html` 里四处 `?v=` 一起加版本号（styles.css / supabase.js / petConfig.js / app.js，如 `?v=20261121z47`），否则浏览器会用旧缓存，改了 CSS 也看不到效果。

## 货币：洛克贝

唯一的游戏货币，不用经验当钱。

**从哪来**

- 每打完一场战斗 +1（不分场景、不分胜负）
- 给学生点赞 +5（见排行榜一节）
- 老师后台发放（单个加减、全员 +60、每周排行榜奖励）
- 市场卖道具收入（会扣手续费）

**花到哪去**

- 咕噜球（5 / 10 / 18 / 30 / 60 / 120）
- 刷新第一只宠物 50
- 宠物升级（见数值表）
- 时装 10000 一套，或用该场景道具凑 100 个

## 宠物系统

- **上限 6 只**（`MAX_PETS`），宠物栏固定 6 格。
- 第一只宠物：经验 ≥ 120（`HATCH_EXP_REQUIREMENT`）解锁孵化，孵出来是随机初始宠物；不满意花 50 洛克贝重抽（`PET_REFRESH_COST`），重抽后回到 Lv.1、经验清零。
- 第 2 只起只能靠野外捕捉：战斗打赢后有 15% 概率弹捕捉窗，**只要宠物不满 6 只就会弹**（`profile.pets.length < MAX_PETS`）。宠物满了再抓会提示「宠物栏已满」。
- 每只宠物有独立等级、经验、亲密度，切换出战用宠物栏里的卡片。
- 属性由等级自动算，学生不用管：HP 80 起、攻击 10+等级×2、防御 8+等级×1.5、速度 8+等级×1。异色宠物攻击额外 +5。
- 战斗力 = 各属性加权总分，排行榜按该角色**全部宠物**战力求和。
- 升级花费（`getUpgradeCost`）：Lv≤10 → `110+70×等级`；Lv≤30 → `220+110×等级`；更高 → `450+170×等级`。
- 进化：Lv.36 进第二阶段，Lv.54 进第三阶段；没有第三阶段的宠物不再进化。进化不花钱。
- 异色宠物：野外遇敌 1% 概率出异色（`shinyRate`），共用 3 只异色立绘。

## 亲密度与场景道具

- 10 个场景各 4 个专属道具，共 40 个，图标是内嵌 SVG。
- 探索时 18% 概率掉道具（`ITEM_DROP_CHANCE`）；**每个场景第 5 个探索点掉率 70%**，掉落时本场景主打道具 50%，其余三种平分。
- 集齐某场景 4 种道具 → 该宠物亲密度 +1；每个场景对每只宠物只算一次（`bondScenes` 记录）。
- 亲密度上限 10；**达到 3 级永久解锁宠物改名**。
- 场景按亲密度解锁：0 级开轻风草原，每 +1 级开下一个。

## 大世界：10 个场景

每个场景 6 个探索点，等级段依次抬高，同一场景内所有宠物等概率出现（异色单独 1%）。

| 场景 | 野生等级 | 6 个探索点等级段 | 遇敌率 |

| 维苏威火山 | 11-20 | 11-12 / 12-15 / 14-17 / 16-19 / 17-20 / 20 | 50% |
| 人鱼湾 | 21-30 | 21-22 / 22-25 / 24-27 / 26-29 / 27-30 / 30 | 50% |
| 皇家研究院 | 31-40 | 31-32 / 32-35 / 34-37 / 36-39 / 37-40 / 40 | 50% |
| 雪人谷 | 41-50 | 41-42 / 42-45 / 44-47 / 46-49 / 47-50 / 50 | 65% |
| 雷鸣峡谷 | 51-60 | 51-52 / 52-55 / 54-57 / 56-59 / 57-60 / 60 | 65% |
| 幽暗森林 | 61-70 | 61-62 / 62-65 / 64-67 / 66-69 / 67-70 / 70 | 65% |
| 暗影沼泽 | 71-80 | 71-72 / 72-75 / 74-77 / 76-79 / 77-80 / 80 | 65% |
| 龙之秘境 | 81-90 | 81-82 / 82-85 / 84-87 / 86-89 / 87-90 / 90 | 65% |
| 天空之城 | 91-100 | 91-92 / 92-95 / 94-97 / 96-99 / 97-100 / 100 | 65% |

每个探索点的经验区间见 `SCENE_SPOTS`（如草原 7-30 到 90-112）。经验只在**没遇敌**的那次探索给，并有 `expComp` 补偿系数把遇敌率折算掉，再乘场景倍率 `SCENE_EXP_MULT`（草原 1、火山 1.4……天空之城 2.6），保证「一个场景探索 100 次左右」刚好升到该场景满级。

**探索点悬停面板**：鼠标停在任一探索点上，会展开一张深色小卡片，三条信息——`🐾 野生宠物 Lv.a-b`（取 `WILD_PETS[场景].levels[该点序号]`）、`⚔️ 遇敌概率 x%`（`encounterRate`）、`🎁 道具概率 y%`（第 5 个点 70%，其余 18%，即 `ITEM_DROP_CHANCE`）。移开鼠标自动收起；`y < 34%` 的点改成向下展开，`x < 22%` / `x > 78%` 的点向内对齐，避免被 `.scene-stage` 的 `overflow:hidden` 裁掉。这里刻意不用 CSS 过渡——本项目在后台标签页会冻结动画，透明度停在 0 会导致面板永远看不见。

## 多人可见（同学互相看见）

同一场景里，学生能看见别的同学在走动，带的是哪只宠物、穿的是哪套时装。**本期只做"看见"**：不能点对方、不能聊天、不能交易、不能对战。

| 项 | 做法 |
|---|---|
| 房间 | 一个场景一个频道 `carlosia:room:{sceneId}`，大世界是 `carlosia:room:world` |
| 位置 | 只在频道里广播，**不写数据库**，存档链路完全不受影响 |
| 发送频率 | 走动时最多 800ms 一次，停下立刻补一发；心跳 5 秒一次 |
| 坐标 | 按底图归一化后传递，1366×768 和 1920×1080 两种窗口在同一位置能重合 |
| 上限 | 单场景 20 人；超过就忽略新来的 |
| 消失 | 对方关页面靠 presence 离开，兜底 12 秒没消息自动淡出，不留鬼影 |
| 断线 | 自动退避重连 3 次，仍失败就静默关闭多人功能，单人玩法照常 |
| 宠物/名字 | 名字是头顶小木牌；出战宠物显示在脚边，换装换宠会立刻更新 |

一键关掉：`app.js` 顶部 `PEERS_ENABLED = true` 改成 `false`，立刻回到纯单机版。
## 战斗规则

- 全自动，逐行日志，30 回合上限（`round < 30`）。
- **胜负都不给经验**。只要遇上敌人打完，不论输赢都 +1 洛克贝；打赢额外有 15% 概率弹捕捉窗（宠物未满 6 只时）。
- 打输有 50% 概率被抢走 1 个背包道具（背包空则不抢）。
- 越级保护：野生宠比你高 1-2 级时，给你补攻击 +3/级、防御 +2/级（最多按 2 级算），否则差 1 级就必输。
- 战斗弹窗约 3.5 秒自动关闭，捕捉窗会等战斗演出播完再弹，避免两个弹窗叠在一起。
- **遇敌不再弹右上角提示**：以前「战斗开始」「没有咕噜球」会盖在战斗弹窗上，属于重复信息（战斗弹窗自带胜负和结算行，捕捉窗里也有「你没有咕噜球！可以临时购买」的说明和按钮），已整体去掉。剩下必须提醒的事（排行榜解锁、道具快集齐、亲密度提升等）改为**单条显示**：同一时间只有一条，新提示直接顶掉旧的，2 秒自动消失。

## 道具与市场

- 道具只用于集亲密度和卖钱。40 个道具各有参考价（`ITEM_PRICES`），范围 150 ~ 1100。
- **我要卖**：自由定价，点道具卡片弹价格输入框，范围 2 ~ 99999，默认填参考价。上架后道具从背包扣除。
- **逛市场**：花洛克贝买别人的道具，不能买自己的。
- 卖家到手 = 售价 − 手续费（20%，向上取整，`MARKET_FEE_RATE`）。
- **我的上架**：可随时下架退回背包。
- 市场挂单存云端表 `market_listings`；云端连不上时读本地缓存 `carlosia_market_v1`。

## 时装

- 共 11 套：新手装（免费自带）+ 10 套场景主题，男女各一套立绘。
- 两种兑换：10000 洛克贝，或该场景道具凑够 100 个（`OUTFIT_PRICE` / `OUTFIT_ITEM_NEED`）。
- 衣柜里点卡片即换装，锁着的灰掉。

## 排行榜与点赞

三个榜：**战力榜**（全部宠物战力求和）、**财富榜**（洛克贝余额）、**时装榜**（已解锁套数，老账号没有字段按 1 套算）。

- 数据从云端拉全班名单，缓存 60 秒；演练账号（名字含「测试/引导/demo/test」）不上榜，但他们点的赞照样算数。
- **点赞**：点别人 +5 洛克贝给自己，被赞者「获赞」+1；每人每天每个榜 3 次（`LIKE_PER_DAY`），零点自动重置；不能给自己点；额度用完按钮变「明天再来」。
- 被赞总数 = 全班所有人 `likesSent` 里对某人的求和（`sumLikesFor`），不互相写对方存档，避免被覆盖。
- 角色面板有「被赞 N 次」一格，打开面板时异步刷新。
- 老师后台点「排行榜」弹出只读榜单，没有点赞按钮。

点赞成功那一刻，屏幕中间会弹一下「🎉 恭喜获得 / +5 洛克贝 / 当前 xx 个」，1 秒后自动淡出，不挡操作、不用点确认。
## 角色面板

- 信息页一次性操作（`buildRoleActions`）：**性别互换 1 次**、**改密码 1 次**（改成 4 位数字，改完即刻写云端）。
- 两个按钮用过后变灰显示「已换过」「密码已改过」。

## 新手引导

- 13 步**点击式**引导（`GUIDE_STEPS_V2`）：宠物 → 孵化 → 洛克贝 → 进入草原 → 探索点 → 结果 → 商店 → 时装页 → 角色页 → 性别互换（演练，不真扣次数）→ 改密码（演练）→ 衣柜 → 换装。
- 每步先关掉挡路弹窗再高亮目标；演练步骤会拦掉真实点击，只提示「这是演练」。
- 老账号没有孵化按钮时自动跳过该步。
- 老师后台有「重置引导」，可让全班重新看一遍。

## 数据存储

**本地 localStorage**

| key | 内容 |
|---|---|
| `carlosia_phase1_save_v1` | 老师电脑上的本地基档（不覆盖云端） |
| `carlosia_phase1_save_v1_cloud_<学生名>` | 学生整份存档 |
| `carlosia_phase1_save_v1_cloud_teacher` | 老师端 |
| `carlosia_market_v1` | 市场本地缓存 |

页面约每 2 秒合并写一次云端，连点探索不会刷爆接口；`cloudRequest` 默认 8 秒超时，拉全班名单用 25 秒。

**Supabase**

- `students` 表：`name`（唯一）、`pass`、`save`（jsonb，整份存档）、`updated_at`
- `market_listings` 表：`id`、`seller_id`、`seller_name`、`item_id`、`item_name`、`price`、`listed_at`

## 已知限制

- 点赞额度、天数按设备日期算，学生改系统时间可以多刷。
- 被赞数不是实时推送，别人点完你这边要重新打开榜/面板才更新。
- 时装榜目前多数人只有新手装 1 套，排序没有区分度，等大家买了才有差别。
- 排行榜依赖云端，网络差时会提示「网络有点慢，没读到全班名单」。
